# Character Profiler Roadmap

The roadmap follows the product specification rather than adding features simply because they are technically possible. Detailed release history belongs in `CHANGELOG.md`; this document records milestones and deliberate future candidates.

## Completed milestones

### 0.3.1 — Stabilisation and definition
Established the first build-clean baseline, product specification, feature-status audit, architecture boundaries and development roadmap.

### 0.4 — Family tree
Delivered the relationship-derived graphical family tree, multi-generation traversal/navigation and structural validation for duplicate links and ancestry contradictions.

### 0.5 / 0.5.1 — Character Guide depth
Delivered the stable prompt catalogue, genre/development scoring, category balancing, adaptive context and human-readable suggestion reasons.

### 0.6 — Author workflow and portability
Delivered archive format v1, story backup/restore, fresh local IDs, graph reconstruction, validation, project metrics and round-trip coverage.

### 0.7 — Visual Studio hardening
Delivered runtime Image Playground availability handling, author-controlled references, canonical-image lifecycle, eight fixed 2D turnaround angles and deterministic visual-state tests.

### 0.8 — Author-release hardening
Delivered editable/reorderable history, inverse-safe relationship editing, searchable large-cast workflows, migration regression coverage, accessibility improvements and failure surfacing.

### 1.0.x — Stable baseline and audit hardening
Delivered non-destructive startup recovery, transactional save/rollback, stable profile identifiers, saved Guide-answer management, stricter archive/relationship safety, release-quality packaging and compiled AppIcon integrity verification.

### 1.1.0 — iPhone workflow refinement and real 3D reconstruction
Released the redesigned Story Library/workspace hierarchy, character dashboard, revised editing flow and optional RealityKit photogrammetry path. The 3D USDZ remains temporary inspection output rather than persistent/archive-v1 data.

### 1.1.1 — Interface flow and usability
Released direct Profile editing, unsaved-change protection, clearer 2D Appearance versus 3D Reconstruction modes, cancellable reconstruction, improved Dynamic Type/light-mode behaviour, consistent Visual Studio styling and family-tree centring/recenter controls. Version 1.1.1 is build 17, keeps the existing SwiftData schema and retains archive format v1.

## Outstanding physical-device checks

Hosted CI proves SDK integration and compilation, not aesthetic output quality. A supported physical iPhone is still required to assess:

- actual Image Playground generation and device-specific availability flow;
- canonical/turnaround consistency of face, body proportions, clothing, colours and equipment; and
- RealityKit photogrammetry reconstruction quality with real overlapping multi-angle photographs.

## Future candidates, not commitments

The following require a deliberate product decision before entering numbered scope:

- semantic contradiction/consistency analysis across character facts;
- broader visual relationship network for non-family links;
- iCloud synchronization;
- additional visual-AI provider abstraction;
- richer archive history/comparison;
- package-based archive assets if JSON backups become impractical;
- iPad-specific layouts;
- Mac companion application; and
- persistent/exportable 3D character assets or model-editing beyond the temporary photogrammetry preview.

## Explicitly outside the roadmap

Unless the product specification is deliberately changed, Character Profiler does not include scene/video generation, character animation, a game engine, RPG mechanics, automatic chapter/story writing or a large posing studio.
